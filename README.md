## Summary

In this lab, we learned about edge sensitive circuits and how flip flops work. We used Verilog to make three types of flip flops: D, JK, and T. We learned how each one changes or holds its output when the clock is triggered. We also used switches for inputs and LEDs to see the outputs on the board. The main goal was to understand how flip flops store data and control when the output changes.

## Lab Questions

### What is difference between edge and level sensitive circuits?

Level sensitive circuits change while the signal is high, but edge sensitive circuits only change when the signal goes from low to high.

### Why is it important to declare initial state?

It is important because it makes sure the circuit starts with a known value instead of an unknown one.

### What do edge sensitive circuits let us build?

They let us build things like counters, memory, and other circuits that change based on a clock signal
